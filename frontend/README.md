# YatraSathi Frontend (React.js + Tailwind CSS)

Built with **React.js (JavaScript JSX)** and styled with **Tailwind CSS**, replicating the design and workflow of the YatraSathi Trip Planner module.

## Available Views & Components

1. **`Navbar.jsx`**: Global brand navigation, view switching tabs, and live Python FastAPI connection indicator.
2. **`TripPlannerView.jsx`**: Complete expedition intake form, dynamic budget tier slider, guest stepper, travel vibes, and featured destinations.
3. **`GeneratingItineraryView.jsx`**: Live synthesis canvas with animated progress rail, engine checkpoint checklist, and status ticker.
4. **`SmartItineraryView.jsx`**: Multi-day itinerary schedule with budget utilization tracker, stops timeline, and local insider advice.
5. **`RouteMapBudgetView.jsx`**: Spatial vector map with glowing paths, floating stop pins, elevation profile, and categorized ledger breakdown.
6. **`Footer.jsx`**: Consistent footer layout.

## Running the Frontend

```bash
cd frontend
npm install
npm run dev
```

Visit [http://localhost:5173](http://localhost:5173).
